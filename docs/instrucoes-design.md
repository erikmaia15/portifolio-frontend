Quero criar este frontend do zero.

USE OBRIGATORIAMENTE a skill "design-taste-frontend" durante todo o desenvolvimento.

Não quero um frontend com aparência genérica de IA, template ou dashboard padrão.

Antes de escrever código:

1. Leia e siga as instruções da skill "design-taste-frontend".
2. Analise o objetivo do projeto e defina uma direção visual própria.
3. Escolha uma identidade visual coerente, incluindo tipografia, paleta de cores, espaçamento, grid, formas, componentes e hierarquia visual.
4. Evite padrões visuais clichês de sites gerados por IA, como excesso de cards, glassmorphism genérico, gradientes aleatórios, sombras exageradas, cantos excessivamente arredondados e layouts previsíveis.
5. Priorize design editorial, composição, hierarquia, contraste e personalidade visual.

Depois: 6. Crie toda a estrutura do frontend. 7. Implemente as páginas e componentes necessários. 8. Garanta responsividade para desktop, tablet e mobile. 9. Adicione microinterações e animações apenas quando fizerem sentido para a experiência. 10. Mantenha o código organizado, reutilizável e fácil de manter. 11. Não use conteúdo ou componentes genéricos apenas para preencher espaço. 12. Ao finalizar, faça uma revisão visual do projeto seguindo novamente as regras da skill e corrija o que ainda parecer "AI-generated".

IMPORTANTE:

- A skill "design-taste-frontend" deve ser considerada uma regra de design durante toda a implementação.
- Não comece codificando imediatamente. Primeiro analise o projeto e defina a direção visual.
- Se alguma decisão de design não estiver especificada, tome uma decisão própria e coerente em vez de usar um template genérico.
